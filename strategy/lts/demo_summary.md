**เปลี่ยน default เป็น limit แล้วทั้งใน backtest และ live:**
- `backtest_s420.py`/`backtest_s421.py` — default `--order-type` เปลี่ยนจาก `market` เป็น `limit`
- `detect_s420()`/`detect_s421()` — คืน `order_type: "limit"`, `entry: fib_ew` เสมอ (เดิม `market` +
  `entry: close`) — เงื่อนไขเข้าไม้เปลี่ยนจาก "close ต้องอยู่ในโซน EW แล้ว" เป็น "pattern match ก็พอ"
  (ไม่ต้องรอ close ผ่านโซนมาก่อนแบบ market)
- `demo_portfolio.py` — สร้างระบบ pending/limit order จริงใหม่ทั้งชุด (`_place_limit_order()` ผ่าน
  `mt5.TRADE_ACTION_PENDING`, `_process_pending_limit_order()` เช็ค fill/cancel ทุกรอบ scan ผ่าน
  `mt5.orders_get()`) — เดิมทั้งระบบ (ทุก portfolio รวม S101-S111) มีแต่ market order ล้วนๆ

**Lot sizing แบบใหม่:** เปิด `DEMO_PORTFOLIO_BALANCE_LOT_ENABLED` เฉพาะ S420/S421 — คำนวณ
`lot = balance/10000` จาก balance จริงของบัญชี (auto-scale ไม่ต้องตั้ง fix lot เอง) ต่างจากพอร์ตอื่น
