# S20.13 Command Reference

หน้านี้รวบรวมคำสั่งสำหรับใช้งานสคริปต์ Backtest ของกลยุทธ์ `S20.13` (Quant Sniper - Price Action & Volatility Fuel) คุณสามารถก๊อปปี้คำสั่งในกรอบสีดำไปรันที่ Terminal ได้เลย

---

### 1. การรัน Backtest เบื้องต้น (`backtest_s20.13_runner_mt5.py`)

สคริปต์ Backtest สำหรับ S20.13 จะดึงข้อมูลจาก MT5 ทำการสแกนหา Liquidity Sweep ตามด้วย PA Confirmation (CHoCH / Engulfing) พร้อมทั้งจำลองระบบจัดการความเสี่ยง (Breakeven ที่ SD 1.5)

**คำสั่งรันแบบดูผลลัพธ์บนจอและ Export เป็น CSV:**
```bash
python strategy/s20.13/backtest-sim/backtest_s20.13_runner_mt5.py --days 30 --tf H1 --compound 1.0
```
*(คำสั่งนี้จะทำการเทสย้อนหลัง 30 วัน, สแกนเฉพาะ Timeframe H1, ทบต้น 1.0 และบันทึกผลลัพธ์ไว้ในไฟล์ CSV)*

**คำสั่งรันสแกนทุก Timeframe (M1 ถึง D1):**
```bash
python strategy/s20.13/backtest-sim/backtest_s20.13_runner_mt5.py --days 30 --tf all --compound 1.0
```

**คำสั่งรันแบบบันทึก Log ลงไฟล์เท็กซ์ (กันหน้าจอไหล):**
```bash
python -u strategy/s20.13/backtest-sim/backtest_s20.13_runner_mt5.py --days 30 --tf H1 > bt_s20_13_out.log 2>&1
```

---

### 2. พารามิเตอร์ที่รองรับ
- `--days N` (ระบุจำนวนวันที่ต้องการเทสย้อนหลัง เช่น 30, 60, 90)
- `--tf X` (ระบุ Timeframe เจาะจง เช่น M15, H1, หรือ all)
- `--compound N` (ระบุเปอร์เซ็นต์ความเสี่ยง/พอร์ต สำหรับคำนวณ Lot Size)

---

### 3. ผลลัพธ์และไฟล์ Excel (CSV)
ทุกครั้งที่รัน Backtest สำเร็จ สคริปต์จะทำการ Export ออเดอร์ทั้งหมดไปที่:
`strategy/s20.13/excel/s20_13_sim_trades.csv`

คอลัมน์ในไฟล์ประกอบด้วย:
- `Time (BKK)`: เวลาที่เกิดสัญญาณเข้า
- `Close Time`: เวลาที่ออเดอร์ถูกปิด
- `TF`: Timeframe
- `Type`: ฝั่ง BUY / SELL
- `Entry`, `SL`, `TP`: ราคาเข้า, จุดตัดขาดทุน (ดึงตาม ATR), เป้าหมาย SD 2.6
- `Lot`, `P&L`, `Balance`: ขนาดล็อต, กำไร/ขาดทุน, ยอดเงินคงเหลือ
- `Reason`: เหตุผลที่ปิดออเดอร์ (มี 4 แบบ: `WIN` ชน TP, `SL` ขาดทุน, `BE` เตะหน้าทุนที่ SD 1.5, `OPEN` ออเดอร์ยังค้างอยู่)

---

### 4. ฟีเจอร์พิเศษของกลยุทธ์ S20.13
- **Volatility Time-Scaling (Fuel):** มีการใช้ ATR คูณด้วย Square Root ของเวลา (เช่น H1 ไป D1 ใช้สูตร `√(1320/60) = 4.70`)
- **Strict PA Confirmation:** ออเดอร์จะเปิดก็ต่อเมื่อมีแท่งเทียนกลืนกิน (Engulfing) หรือทะลุโครงสร้าง (CHoCH) คอนเฟิร์มการกวาด Liquidity (Sweep) เท่านั้น ช่วยกรอง Whipsaw loss ออกไปได้มหาศาล
- **Breakeven (SD 1.5):** หากราคาวิ่งไปถึง 1.5 เท่าของ Fuel (SD 1.5) ระบบจะขยับ Stop loss มาบังหน้าทุน (Entry) อัตโนมัติ เพื่อป้องกันการขาดทุน
