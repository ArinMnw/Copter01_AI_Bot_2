# บทสนทนาการเพิ่มกลยุทธ์ S20.14 (Full Trading)

**ผู้ใช้ (พี่):**
ให้ช่วยสร้างกลยุทธ์ Full Trading เป็น S20.14 โดยมีเงื่อนไข RSI Divergence, Bullish/Bearish Engulfing, FVG (Fair Value Gap) และกำหนด SL/TP ผ่าน ATR พร้อมตั้งค่า SL ที่บริเวณปลายไส้เทียน 
นอกจากนี้ให้เชื่อมต่อตัวแปร Toggle เปิด/ปิด และการทำงานของระบบลงในไฟล์ `config.py`, `scanner.py`, เมนู Telegram ใน `keyboard.py` และ `callback_handler.py` และสร้างบอทรัน Backtest 30 วันด้วยค่ะ

**อลิซ (บอท):**
อลิซดำเนินการสร้างระบบและทดสอบ Backtest เรียบร้อยแล้วนะคะพี่! 🚀

รายละเอียดสิ่งที่อลิซได้ทำการสร้างและปรับปรุงทั้งหมดมีดังนี้ค่ะ:
1. **สร้างระบบแกนหลัก (Core Logic):**
   - อลิซได้สร้างไฟล์ `strategy/s20.14/strategy20_14.py` เพื่อตรวจสอบสัญญาณตามเงื่อนไขพี่บอกทั้งหมดค่ะ ได้แก่ การหา RSI Divergence แบบ Classic, การเกิด Bullish/Bearish Engulfing (เนื้อคลุมเนื้อ) และการมี FVG ยืนยันการไปต่อของราคา
   - คำนวณ SL จากปลายไส้เทียนของ Swing +/- 1.0 ATR และ TP = 1.618 Fib (ประมาณ 1.6:1 RR)
2. **สร้างระบบ Backtest:**
   - สร้างไฟล์ `strategy/s20.14/backtest-sim/backtest_s20.14_runner_mt5.py` จำลองการรันจริงแบบ Compound 2% ค่ะ
3. **ปรับแต่งการตั้งค่า (Configurations & Core):**
   - ใน `config.py`: อลิซเพิ่ม `S20.14` ลงใน `active_strategies`, เพิ่มค่า Default ปิด-เปิดตาม TF รวมถึงได้อัปเดต Skip Rules Guard ทุกรูปแบบไม่ให้มาขวาง Logic และเซฟค่าลงระบบ `save_runtime_state()` / `restore_runtime_state()` แล้วค่ะ
   - ใน `scanner.py`: อลิซนำเข้า Logic เข้ามาให้ตรวจจับราคาพร้อมกับกลยุทธ์อื่น ๆ ได้เลย
4. **เชื่อมต่อ Telegram UI:**
   - เพิ่มปุ่มกดสลับโหมดเปิด/ปิด Timeframe สำหรับ S20.14 ลงในเมนูหน้า `keyboard.py` และตั้งค่า callback ลอจิกให้ใช้งานได้เรียบร้อยผ่าน `callback_handler.py` ค่ะ
